# Warp Desktop

Aplicativo Tauri 2 para Windows com as funcionalidades atuais de contas, perfis e sessões. Reutiliza a interface web; usa o Gerenciador de Credenciais do Windows para sessões persistentes e requisições HTTPS nativas. Consulte `../../docs/BUILD_WINDOWS.md` para compilar e conectar à API pública. Chat e voz ainda dependem das próximas fases.
